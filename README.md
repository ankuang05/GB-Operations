# OpsLink

Planning documents for a role-based workforce and operations platform: an iOS app for warehouse floor staff and a web application for management, sharing one backend.

First customer: Goldberry Distributors, a food distributor operating four warehouses in the California Bay Area and Sacramento regions.

## Documents

| Document | Contents |
|---|---|
| `docs/PRD.md` | Product requirements, roles, release scope, success metrics |
| `docs/ENGINEERING-DESIGN.md` | Architecture, data model, security design, ADRs |
| `docs/ROADMAP.md` | Sprint schedule with dates, sized for a 2-person part-time team |
| `docs/ORCHESTRATION.md` | Per-step agent execution chains for the build |

## Status

Planning only. No implementation has started.

First release targets a pilot on 2027-02-15 and general availability on 2027-03-08, built at roughly 25 engineer-hours per week.
